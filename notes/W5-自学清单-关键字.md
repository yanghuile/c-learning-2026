# W5 自学清单：volatile / static / const

> 这是你 W5 的最后一块内容。学完它，W5 就完整了。
>
> **你的基础**（我先诊断过）：
> - `const`：✅ 用过 12 个文件，还专门练过"const 与指针"
> - `static`：⚠️ 只在注释里见过，**几乎没概念**
> - `volatile`：❌ **完全没概念**（这是嵌入式最重要的一条）
> - `extern` / `register`：❌ 没用过

---

## 一、三块内容 + 重要程度

| # | 关键字 | 重要度 | 为什么 |
|---|---|---|---|
| 1 | **`volatile`** | ⭐⭐⭐⭐⭐ | **嵌入式第一关键字**；STM32 头文件里每个寄存器都带它；面试必问 |
| 2 | **`static`** | ⭐⭐⭐⭐ | 两种含义（局部静态 / 文件级私有），驱动代码里到处是 |
| 3 | `const` | ⭐⭐⭐ | 你已经会基础，重点补"和 volatile 同时用" |
| 4 | `extern` / `register` | ⭐⭐ | 多文件工程要用（W6 拆工程时会遇到） |

## 三、学完必须能回答的问题（我会考这些）

### `volatile`（重点）

1. **`volatile` 的作用是什么？** 用一句话说清楚（提示：它阻止编译器做某件事）
2. **哪三个场景必须用 `volatile`？** 各举一个例子
3. **为什么寄存器指针必须写成 `volatile uint32_t *`？** 如果不加会怎样？
4. **`volatile` 和 `const` 能同时用吗？** 什么场景下两个都要？

### `static`

5. **函数里的 `static int count = 0;`** 和普通的 `int count = 0;` 有什么区别？
6. **文件里的 `static void helper()`** 和 `void helper()` 有什么区别？
7. `static` 修饰**全局变量**时，作用是什么？

### `const`

8. 这四种写法分别是什么意思？
   ```c
   const int *p;          /* ? */
   int * const p;         /* ? */
   const int * const p;   /* ? */
   int const *p;          /* ? （这个和第一个一样吗） */
   ```

### 多文件（`extern`）

9. **头文件里写 `extern int g_count;`**，源文件里写 `int g_count = 0;` —— 为什么这样分？
10. 如果头文件里**不写 `extern`**，直接写 `int g_count = 0;` 会有什么问题？

## 四、动手练习

**建一个文件 `exercises/W5-关键字练习.c`，完成三件事：**

### 练习 1：验证 `static` 的"记忆"特性（最重要）

```c
/* 写两个函数，各有一个计数器：
 *   counter_normal()  —— 用普通局部变量
 *   counter_static()  —— 用 static 局部变量
 *
 * 各调用 3 次，打印计数器的值，对比差别。
 * 然后回答：为什么 static 版本能累加？
 */
```

### 练习 2：验证 `volatile` 的必要性（进阶）

```c
/* 用 -O2 优化级别编译，对比加/不加 volatile 的结果：
 *
 *   volatile int flag = 0;
 *   while (flag == 0)
 *   {
 *       // 空循环，等别的"东西"把 flag 改掉
 *   }
 *
 * 编译命令：
 *   gcc -O2 -o test test.c
 *
 * 提示：不加 volatile 时，编译器可能认为"flag 从来没人改"，
 *       直接把循环优化成死循环或删掉。加了 volatile 才不会。
 *
 * 如果看不出来，用 gcc -O2 -S 生成汇编，对比两种写法的汇编代码。
 */
```

### 练习 3：`const` 的四种写法

```c
/* 照着 W3-Day3-pointer-const.c 的风格，
 * 把四种 const 写法都写一遍，每种都故意试一次非法操作，
 * 看编译器的报错信息（就像你当初学 p1 那样）。
 */
```

## 六、明天的验收方式

我会出题，重点考：

| 方向 | 具体 |
|---|---|
| **概念辨析** | `volatile` vs 普通变量、`static` 的两种含义 |
| **代码预测** | 给一段代码，预测输出（比如 static 计数器的值） |
| **嵌入式实战** | 解释 STM32 头文件里的 `volatile uint32_t`；`volatile const` 的用途 |
| **找 bug** | 一段"缺 volatile 导致编译器优化出错"的代码 |

**特别提醒**：这是**面试最高频**的一块。汇川的技术面即使不问八股，问到寄存器操作时也可能问 `volatile`。
