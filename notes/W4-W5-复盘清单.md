## 二、W5 你答错/没答的内容（🔴 必看，20 分钟）

### 2.1 位运算 —— 无符号右移（你答错的那题）

**文件**：[W5-位运算验收.c](W5-位运算验收.c) 第 2-2 题（约 81 行）

```c
unsigned int uneg = 0xFFFFFFF8u;
printf("0xFFFFFFF8 >> 1 = 0x%X\n", uneg >> 1);
```

- 你的答案：`0xFFFFFFFC`
- 正确答案：**`0x7FFFFFFC`**

**要记住的**：

| 类型 | 右移时最高位补 | 名称 |
|---|---|---|
| **有符号** `int`（负数） | 补 **1** | 算术右移 |
| **无符号** `unsigned` | 补 **0** | 逻辑右移 |

**同一个二进制数，一个变成 21 亿，一个变成 -4。**

**为什么重要**：嵌入式里处理 ADC 值、寄存器内容、协议字段**一律用 `unsigned`**，
就是为了避免符号位带来的意外。

### 2.2 代码风格：`return value |= (1<<n);`

**文件**：[W5-位运算验收.c](W5-位运算验收.c) 的三个函数（约 209–234 行）

```c
return value |= (1<<n);     /* 你写的：能跑，但不清晰 */
return value |  (1<<n);     /* 更好的写法 */
```

**问题**：`|=` 改了 `value` 这个局部变量，再把它返回。功能对，但读代码的人要绕一下。

## 五、W5 关键字（🔴 必看，10 分钟）

**文件**：[W5-关键字练习.c](W5-关键字练习.c)（74 行）

**重点看练习二**（`volatile`）：

```c
volatile int flag=0;
void interrupt() { flag=1; }
int main() { while(flag==0) { } }    /* ← 死循环，因为没人调用 interrupt() */
```

**这个练习"失败"了，但失败本身就是知识点**：

- `volatile` 解决的是"**编译器优化**"问题
- **不解决"程序逻辑"问题** —— 你的 `interrupt()` 从来没人调用，所以循环永远出不来
- 要看到 `volatile` 的价值，要**读汇编**或**跑真实硬件**

**验证方法**（有空可以再试一次）：

```powershell
gcc -O2 -S test.c        # 生成汇编，对比加/不加 volatile 的 main
```
